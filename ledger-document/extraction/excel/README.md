# Excel extraction skills

Format-specific and vendor-specific skills for statements delivered as Excel/CSV go here (e.g. a
PFC or carrier's own spreadsheet layout quirks -- loan-header-plus-coverage-sub-row blocks,
column conventions, that kind of thing). Loaded alongside
`ledger-document/extraction/general-guidelines` whenever the source document is xlsx, xls, or
csv -- not loaded for PDF or email documents.

No Excel-specific skill exists yet -- extraction for spreadsheets currently relies on
general-guidelines plus the model's own reading of the document.
