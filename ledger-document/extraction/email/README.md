# Email extraction skills

Format-specific and vendor-specific skills for statements delivered as email (e.g. a funding
confirmation sent as the email body rather than an attachment) go here. Loaded alongside
`ledger-document/extraction/general-guidelines` whenever the source document is an email -- not
loaded for PDF or Excel documents.

No email-specific skill exists yet -- there's no email ingestion path in the app yet either (see
DPM-1136, the planned Graph API email listener). This folder exists so the convention is in place
before that lands.
