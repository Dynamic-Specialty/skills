# PDF extraction skills

Format-specific and vendor-specific skills for statements delivered as PDF go here (e.g. a
carrier or PFC's own PDF-rendered layout quirks). Loaded alongside
`ledger-document/extraction/general-guidelines` whenever the source document is a PDF -- not
loaded for Excel or email documents.

No PDF-specific skill exists yet -- extraction for PDFs currently relies on general-guidelines
plus the model's own reading of the document.
